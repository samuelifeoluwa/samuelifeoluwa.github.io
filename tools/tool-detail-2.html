Banner Grabber

Python Banner Grabber Socket

What it does

  • Asks for target IP address and port number
  • Connects to that IP and port
  • Receives up to 1024 bytes of data (the banner)
  • Prints the banner to the screen
  • Closes the connection

How it works

Banner grabbing is a basic recon technique: connect to an open port and read whatever the service sends back before you've said anything. Many services — FTP, SMTP, SSH, and others — announce their name and version immediately on connection.

This script opens a single TCP socket to the target IP and port, then calls recv(1024) to read up to 1024 bytes of the service's initial response. That raw byte string is decoded into readable text and printed. Note there's no timeout set, so if a service doesn't send data immediately on connect (many modern HTTP servers won't), the script will hang waiting.

Code

import socket

target = input('Enter Ipaddress: ')
port = int(input('Enter port to connect on: '))

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((target, port))

response = s.recv(1024)
print(response.decode())
s.close()
