Web Scraper

Python BeautifulSoup Requests

What it does

  • Asks for a URL
  • Downloads the webpage using requests
  • Parses the HTML with BeautifulSoup
  • Finds all <a> tags with href attributes
  • Prints each href link to the console

How it works

This scraper enumerates links from a page — useful during recon for discovering subpages, parameters, or third-party resources a target site references. It uses requests.get() to fetch the page's raw HTML, then hands that to BeautifulSoup, which parses it into a navigable tag tree.

soup.find_all('a', href=True) searches that tree for every <a> tag that actually has an href attribute, filtering out anchor tags used only for JS click handlers with no real link. Each href is printed as-is. It's intentionally minimal — no deduplication, domain filtering, or recursion — so it works best as a building block you pipe into further filtering rather than a full crawler.

Code

import requests
from bs4 import BeautifulSoup
import re

url = input('Enter the URL of the website you want to scrape: ')
res = requests.get(url)
soup = BeautifulSoup(res.content, 'html.parser')

for link in soup.find_all('a', href=True):
    print(link.get('href'))
